01

理解概念

回到当时的问题

在机房使用大模型工具时，先后遇到安全校验失败、API 403 和 GitHub 密码遗忘，怎样定位？

API 403：账户问题优先

调用返回 403 时，先确认账户是否欠费或余额逾期；余额被阻断时，请求在鉴权阶段就失败，换提示词或换模型都无效。

代理网关与安全校验

机房或校园网络常经代理网关转发请求。代理可能使工具的安全校验通道无法正常建立，表现为自动模式的安全检查无法通过。

遇到这种情况，需要手动切换运行模式，并接受由此带来的权限差异。

账号找回

忘记 GitHub 密码时，走邮箱重置流程：在登录页选择忘记密码，提交注册邮箱，从邮件链接设置新密码。

02

把概念放进示例

01定位一次 403

终端工具突然无法调用模型，返回 403。

  1. 确认错误码与提示信息。
  2. 检查账户余额与欠费状态。
  3. 补缴或切换可用账户后重试。

得到什么
账户恢复后请求正常返回，确认问题不在提示词。

02通过邮箱重置 GitHub 密码

长时间未登录，忘记 GitHub 密码。

  1. 打开 GitHub 登录页，选择忘记密码。
  2. 输入注册邮箱并提交。
  3. 在邮箱中打开重置链接，设置新密码并重新登录。

得到什么
使用新密码成功登录，原账号数据保留。

A MOMENT TO RECALL

API 返回 403 时第一步查什么？

想一想，再展开答案

先查账户是否欠费或余额逾期，而不是先改提示词。

TAKE THIS WITH YOU · 记忆点

Agent 的关键不是会回答，而是会规划并动手。

工具调用是 Agent 连接外部世界的接口。

01

理解概念

回到当时的问题

第一次接触 Agent，它和普通的聊天问答有什么不同？

它是什么

Agent 以大模型作为决策核心，面向一个目标任务，自行拆分步骤、选择并使用工具，直到任务完成。

它与单纯问答的差别在于：问答只输出文本，Agent 还会产生动作，例如读写文件、执行命令、调用外部服务。

能力与边界

常见能力包括任务规划、工具调用、文件读写和命令执行。批量修改文档、运行代码做校验，都属于可以交给 Agent 的项目类任务。

Agent 的行动仍受工具权限与环境限制，结果也不保证正确；涉及删除、覆盖或对外发布时，需要人工确认。

02

把概念放进示例

01把项目里的一处旧命名批量改掉

多个文档使用了旧命名，需要统一替换并确认没有漏改。

  1. 说明要替换的旧名字、新名字和涉及目录。
  2. Agent 读取文件、逐个替换，再搜索确认没有残留。
  3. 人工抽查改动结果。

得到什么
目标文档完成替换，搜索确认旧命名不再出现。

02改完代码后自动跑校验

编辑脚本后担心语法或格式出错，需要先验证再交付。

  1. 让 Agent 执行项目的检查命令。
  2. 读取报错并定位到具体文件。
  3. 修正后重跑，直到检查通过。
bash
python3 -m unittest discover -s tests -v

得到什么
检查命令通过，Agent 汇报改动内容与结果。
